# Лабораторная работа № 6

Доработка страницы заказа: добавлен блок с вариантами ланчей и проверка состава заказа при отправке формы с показом уведомлений.

## Что добавлено на страницу

На странице `order.html` перед блоками выбора блюд появился раздел «Доступные для заказа комбо».

Структура раздела:

- заголовок раздела;
- сетка `.combo-grid` с тремя колонками на широком экране;
- пять блоков комбо `.combo-card` — каждый является flex-контейнером;
- внутри комбо — блоки блюд `.combo-item` с направлением главной оси сверху вниз;
- в каждом блоке блюда есть иконка и подпись;
- отдельный блок с десертом и примечанием «(Можно добавить к любому заказу)».

Состав комбо соответствует заданию:

1. Суп, главное блюдо, салат, напиток.
2. Суп, главное блюдо, напиток.
3. Суп, салат, напиток.
4. Главное блюдо, салат, напиток.
5. Главное блюдо, напиток.

Десерт не входит в обязательный состав ни одного комбо и может быть добавлен к любому из них.

Иконки скопированы в `menu/lunch/`:

- `soup.png`
- `main.png`
- `salad.png`
- `drink.png`
- `dessert.png`

## Оформление блока

Стили находятся в `order.css`:

- `.combo-grid` — grid-контейнер с тремя колонками;
- `.combo-card` — flex-контейнер варианта ланча;
- `.combo-item` — flex-контейнер блюда с `flex-direction: column`;
- подпись блюда имеет размер `14px`, примечание к десерту — `12px`, то есть на 2 пункта меньше;
- при наведении на иконку срабатывает `transform: translateY(-8px) scale(1.1)`;
- для плавности добавлен `transition: transform 0.25s ease`.

На экранах уже 1000 px сетка перестраивается в две колонки, уже 600 px — в одну. Размер иконок и отступы при этом уменьшаются, чтобы комбо не ломались на узких экранах.

## Проверка состава заказа

Логика находится в `order.js` и запускается на событии `submit` формы. Если состав заказа не соответствует ни одному комбо, вызывается `event.preventDefault()`, форма не отправляется, а на странице создаётся уведомление.

Проверяются пять ситуаций:

| Ситуация | Текст уведомления |
| --- | --- |
| Не выбрано ни одного блюда | «Ничего не выбрано. Выберите блюда для заказа» |
| Выбраны все блюда, кроме напитка | «Выберите напиток» |
| Выбран только суп | «Выберите главное блюдо/салат/стартер» |
| Выбран только салат или стартер | «Выберите суп или главное блюдо» |
| Выбраны только напиток и/или десерт | «Выберите главное блюдо» |

Допустимыми считаются наборы:

- суп + главное блюдо + салат + напиток;
- суп + главное блюдо + напиток;
- суп + салат + напиток;
- главное блюдо + салат + напиток;
- главное блюдо + напиток;
- любой из этих наборов с десертом.

## Уведомление

Уведомление создаётся динамически через `document.createElement()` при каждой неудачной отправке. Перед созданием нового уведомления предыдущее удаляется, поэтому на странице всегда не больше одного окна.

Стили уведомления:

- `.notification` — `position: fixed` на весь экран, `display: flex`, центрирование по вертикали и горизонтали, `z-index: 1000`;
- `.notification-box` — белая карточка с чёрной рамкой;
- `.notification-button` — кнопка «Окей 👌» с закруглёнными краями;
- при наведении на кнопку меняются цвет фона и цвет текста;
- по клику на кнопку уведомление удаляется через `remove()`.

Так как контейнер уведомления закреплён через `position: fixed`, при прокрутке страницы оно остаётся по центру экрана.
